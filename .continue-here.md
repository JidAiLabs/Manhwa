## ► GOTCHAS
- `worker.py` / `dashboard/**` need `launchctl kickstart -k`; `tools/` are
  subprocesses. **`pipeline.py` is IMPORTED by the worker, not subprocessed.**
- Config is read per-handler, so a `studio.toml` change needs no restart.
- `jobs.enqueue` DEDUPES on (type, chapter_id, bundle_id, series_id) and the
  payload is NOT part of the key — pass `dedupe=False` for variants, and
  `priority=1` to jump a running sweep.
- `GEMINI_API_KEY` lives in the LOGIN KEYCHAIN: only the launchd worker can
  reach it. A non-interactive ssh session cannot — image steps must be JOBS.
- Chapter `status` is the last successful stage, NOT freshness. Ep38 read
  `rendered` while its video was 4h older than its repaired narration. **After
  any narration change, compare timestamps.**
- zsh does not word-split `$VAR` as a command; write scripts to a file and scp.
